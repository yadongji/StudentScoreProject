# 学科选择逻辑更新说明

## 更新时间
2026-01-22

---

## 问题描述

之前的学科选择逻辑：
- ❌ 只导入带"(赋分)"的学科
- ❌ 跳过所有不带"(赋分)"的学科

这导致了一些问题：
- 如果Excel中只有"语文"、"数学"、"英语"等普通版本的学科，这些学科不会被导入
- 用户期望：如果学科有赋分版本就选赋分的，如果只有普通版本就选普通版本

---

## 修复方案

新的学科选择逻辑：
- ✅ 如果同一个学科有两个版本（一个带"(赋分)"，一个不带），选择带"(赋分)"的
- ✅ 如果只有一个版本（无论是否带"(赋分)"），导入这个版本

---

## 实现细节

### 两步扫描机制

**第一步：扫描所有学科**
```python
subjects_info = {
    '总分': {
        'scored': [6, 7, 8, 9],      # 总分(物理)(赋分)
        'normal': [10, 11, 12, 13]   # 总分(物理)
    },
    '语文': {
        'scored': [],                 # 无赋分版本
        'normal': [14, 15, 16, 17]   # 语文
    },
    '化学': {
        'scored': [30, 31, 32, 33, 34],  # 化学(赋分)
        'normal': [35, 36, 37, 38]        # 化学
    },
    ...
}
```

**第二步：选择版本**
```python
for subject_name, versions in subjects_info.items():
    if versions['scored']:
        # 优先选择赋分版本
        cols = versions['scored']
        print(f"选择: {subject_name}(赋分)")
    elif versions['normal']:
        # 没有赋分版本，选择普通版本
        cols = versions['normal']
        print(f"选择: {subject_name}")
```

## 常见问题

### Q1: 我的Excel中只有"语文"、"数学"、"英语"等普通学科，会导入吗？
**A:** 会。如果只有一个版本（普通版本），系统会导入这个版本。

### Q2: 我的Excel中有"化学"和"化学(赋分)"两个版本，会导入哪个？
**A:** 会导入"化学(赋分)"版本，跳过"化学"版本。

### Q3: 之前导入时有些学科没有导入，现在能导入吗？
**A:** 如果那些学科只有普通版本（无"(赋分)"标记），之前不会导入，现在会导入。

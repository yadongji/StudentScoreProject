# V3.1 更新说明 - 支持"校次"和"班次"别名

## 📋 更新内容

### 新增功能
- ✅ **校名字段别名支持**：除了"校名次"、"年级名次"，现在支持"校次"
- ✅ **班级名字段别名支持**：除了"班名次"、"班级名次"，现在支持"班次"

### 适用范围
本更新同时支持两种Excel格式：

#### 1. 普通格式（单行表头）
- 表头行直接包含字段名
- 支持以下别名：

| 标准字段名 | 支持的别名 |
|----------|----------|
| 校名次 | 校次、年级名次、年级排名 |
| 班名次 | 班次、班级名次、班级排名 |

**示例表头**：
```
考号 | 姓名 | 总分(物理)(赋分) | 总分班次 | 总分校次
```

#### 2. 方向名次格式（双行表头）
- 第3行：学科名称
- 第4行：字段类型
- 支持以下别名：

| 标准字段名 | 支持的别名 |
|----------|----------|
| 方向校名次 | 校次、校名次 |
| 方向班名次 | 班次、班名次 |

**示例结构**：
```
第3行: 考号 | 姓名 | 总分(物理)(赋分) | 化学(赋分)
第4行:      |      | 分数 | 校次 | 班次 | 分数 | 校次 | 班次
```

## 🔧 技术实现

### 修改的文件
- `excel_to_sqlite_v2.py`

### 修改的函数
1. **detect_sheet_columns_simple()** - 普通格式列检测
   - 第532行：添加 `|| '班次' in header`
   - 第534行：添加 `|| '校次' in header`

2. **detect_sheet_columns_v2()** - 方向名次格式列检测
   - 第641行：添加 `|| '校次' in row4_val`
   - 第644行：添加 `|| '班次' in row4_val`
   - 第697行：格式检测添加 `|| '校次' in header || '班次' in header`

### 核心代码

#### 普通格式列检测
```python
# 判断具体是什么类型的列
if '分数' in header or '成绩' in header or header == subject:
    col_map[f'{subject}_score'] = idx
elif '班名次' in header or '班次' in header:  # 新增班次支持
    col_map[f'{subject}_class_rank'] = idx
elif '校名次' in header or '年级名次' in header or '校次' in header:  # 新增校次支持
    col_map[f'{subject}_grade_rank'] = idx
```

#### 方向名次格式列检测
```python
# 分析这几列，提取字段映射
for k in cols:
    row4_val = row4_values[k] if k < len(row4_values) else ''

    if row4_val == '分数':
        col_map[f'{subject_name}_score'] = k
    elif '方向校名次' in row4_val or '校名次' in row4_val or '校次' in row4_val:  # 新增校次支持
        col_map[f'{subject_name}_grade_rank'] = k
    elif '方向班名次' in row4_val or '班名次' in row4_val or '班次' in row4_val:  # 新增班次支持
        col_map[f'{subject_name}_class_rank'] = k
```

## 📝 使用建议

1. **推荐使用标准字段名**：
   - 新建Excel时，建议使用"校名次"、"班名次"
   - 保持与数据库字段名一致，便于维护

2. **别名用途**：
   - 当从其他系统导入数据时，可直接使用"校次"、"班次"
   - 无需手动修改Excel表头

3. **混合使用**：
   - 支持在同一Excel中混合使用不同别名
   - 系统会自动识别并正确映射

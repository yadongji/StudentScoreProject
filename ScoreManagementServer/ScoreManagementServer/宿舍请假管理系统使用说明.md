# 宿舍管理与请假管理系统 - 使用说明

## 📋 系统概述

本系统为学校宿管阿姨、班主任和管理员设计，实现以下功能：

### ✨ 主要功能

1. **宿舍楼管理** - 管理宿舍楼信息（5号楼、6号楼等）
2. **宿管人员管理** - 管理宿管阿姨和楼层管理员
3. **房间床位管理** - 管理宿舍房间和床位分配
4. **查寝记录** - 每晚记录学生就寝情况
5. **请假管理** - 学生请假申请和审批
6. **出勤统计** - 班主任查看班级出勤情况

---

## 🗄️ 数据库设计

### 核心表结构

| 表名 | 说明 | 主要字段 |
|------|------|----------|
| `Dormitories` | 宿舍楼表 | DormitoryName, DormitoryCode, GenderType, FloorCount |
| `DormitoryRooms` | 宿舍房间表 | DormitoryId, FloorNumber, RoomNumber, BedCount |
| `DormitoryBeds` | 宿舍床位表 | RoomId, BedNumber, BedPosition, IsOccupied |
| `DormitoryStaff` | 宿管人员表 | StaffName, StaffCode, DormitoryId, FloorNumber |
| `StudentDormitoryAssignments` | 学生宿舍分配表 | StudentId, BedId, RoomId, AssignDate, IsCurrent |
| `DormitoryCheckInRecords` | 查寝记录表 | StudentId, CheckInDate, CheckInTime, Status |
| `LeaveApplications` | 请假申请表 | StudentId, LeaveType, StartTime, EndTime, ApprovalStatus |
| `HeadTeachers` | 班主任表 | TeacherName, TeacherCode, ClassName |

## 📖 详细使用指南

### 一、宿舍楼管理

#### 添加宿舍楼

**操作步骤：**
1. 选择 `2. 添加宿舍楼`
2. 输入宿舍楼名称（如：5号楼、6号楼）
3. 输入宿舍楼代码（如：D5、D6）
4. 选择性别类型（男/女）
5. 输入楼层数（默认6层）
6. 输入地址（可选）

**示例：**
```
宿舍楼名称: 5号楼
宿舍楼代码: D5
性别: 男
楼层数: 6
地址: 校区东区5号楼
```

#### 查看宿舍楼信息

**操作步骤：**
1. 选择 `5. 查看宿舍楼信息`
2. 系统显示所有宿舍楼的汇总信息

**显示内容：**
```
宿舍楼    代码      类型      总房间    总床位    已住      空余      入住率
──────────────────────────────────────────────────────────────────
5号楼     D5        男        24        96        80       16       83.3%
6号楼     D6        男        24        96        75       21       78.1%
```

### 二、宿管人员管理

#### 添加宿管人员

**操作步骤：**
1. 选择 `3. 添加宿管人员`
2. 查看宿舍楼列表，输入宿舍楼ID

**示例1 - 整栋楼宿管阿姨：**

```
宿舍楼ID: 1
宿管姓名: 王阿姨
工号: D001
楼层: (直接回车)
电话: 13800138001
职位: 宿管阿姨
```

**示例2 - 楼层管理员：**
```
宿舍楼ID: 1
宿管姓名: 张管理员
工号: D003
楼层: 1

职位: 楼层管理员
```

### 四、查寝记录管理

#### 查看查寝情况

**宿管阿姨操作：**

**操作步骤：**
1. 选择 `6. 查看查寝情况`
2. 输入宿舍楼ID
3. 输入楼层（留空查看整栋楼）
4. 输入日期（默认今天）

**显示内容：**
```

楼层: 1
日期: 2026-01-22
总人数: 16, 在寝: 15, 未归: 0, 请假: 1
```

#### 记录查寝

**操作步骤：**
1. 选择 `7. 记录查寝`
2. 选择房间
3. 为每个学生选择状态：
   - `在寝` - 正常就寝
   - `未归` - 未按时归寝
   - `请假` - 已批准请假
   - `外出` - 外出活动
   - `晚归` - 晚归

---

### 五、请假管理

#### 学生申请请假

**操作步骤：**
1. 选择 `8. 申请请假`
2. 输入学号或姓名
3. 选择请假类型：
   - `病假` - 因病请假
   - `事假` - 因事请假
   - `其他` - 其他原因
4. 输入请假原因
5. 输入开始时间（格式：YYYY-MM-DD HH:MM:SS）
6. 输入结束时间（格式：YYYY-MM-DD HH:MM:SS）
7. 输入家长联系方式
8. 系统自动计算请假天数

**示例：**
```
学号: 2024001
请假类型: 病假
请假原因: 发烧去医院
开始时间: 2026-01-22 08:00:00
结束时间: 2026-01-23 08:00:00
家长电话: 13900139001
```

**请假状态：**
- `待审批` - 等待班主任审批
- `已通过` - 已批准，显示"请假不在校"
- `已拒绝` - 已拒绝，需要按时归寝
- `已撤销` - 学生撤销申请

#### 审批请假申请

**班主任操作：**

**操作步骤：**
1. 选择 `9. 审批请假`
2. 查看待审批的请假列表
3. 选择要审批的请假申请
4. 选择审批结果：
   - `已通过` - 批准请假
   - `已拒绝` - 拒绝请假
5. 输入审批备注（可选）

**示例：**
```
选择请假ID: 1
审批结果: 已通过
审批备注: 已与家长确认
```

## 📊 数据库视图说明

### 1. vw_DormitorySummary
**宿舍楼汇总信息**
- 显示所有宿舍楼的统计信息
- 包括总房间数、总床位、已住人数、空余床位、入住率

### 2. vw_FloorCheckInSummary
**楼层查寝情况汇总**
- 宿管阿姨查看每层的查寝统计
- 按日期统计在寝、未归、请假、外出、晚归人数

### 3. vw_StudentDormitoryDetail
**学生宿舍详细信息**
- 显示学生的完整宿舍信息
- 包括宿舍楼、楼层、房间号、床位号、宿管姓名

### 4. vw_DailyCheckInDetail
**每日查寝详细情况**
- 显示每日每个学生的查寝详情
- 包含请假状态判断

### 5. vw_ClassAttendanceDaily
**班级出勤情况（班主任查看）**
- 班主任查看班级每日出勤
- 显示"请假不在校"状态

### 6. vw_LeaveApplicationDetail
**请假申请详细信息**
- 显示所有请假申请的完整信息
- 包含当前是否在请假期间的判断

### 7. vw_RoomOccupancyByStaff
**宿管阿姨查看的房间入住情况**
- 宿管查看负责房间的入住情况
- 显示每个房间的床位和学生名单

## 🔧 技术说明

### 数据库触发器

系统自动维护以下数据：

1. **自动更新房间入住人数**
   - 分配学生时自动增加入住人数
   - 退宿时自动减少入住人数
   - 更新床位占用状态

2. **自动更新时间戳**
   - 修改记录时自动更新 UpdatedAt 字段

### 数据库索引

为提高查询性能，系统自动创建以下索引：

- 宿舍楼、房间、床位的查询索引
- 查寝记录的日期索引
- 请假申请的时间索引
- 学生宿舍分配索引

## 💡 使用技巧

### 1. 批量添加房间

可以编写脚本批量添加房间：
```python
# 示例：为5号楼1-6层每层添加10个房间
for floor in range(1, 7):
    for room in range(1, 11):
        room_number = f"{floor}{room:02d}"  # 101, 102, ..., 610
        system.add_room(1, floor, room_number, 4)
```

### 2. 批量查寝记录

可以使用批量查寝功能：
```python
# 示例：为101房间所有学生记录查寝
status_map = {
    1: '在寝',
    2: '在寝',
    3: '请假',
    4: '在寝'
}
system.batch_record_check_in_by_room(1, 1, 1, status_map)
```

### 3. 统计报表

可以生成各种统计报表：
```python
# 查询最近7天的查寝统计
stats = system.get_check_in_statistics(1)

# 查询宿舍入住率
dorm_stats = system.get_dormitory_statistics()
```

## ⚠️ 注意事项

1. **首次使用必须初始化数据库**
   - 运行系统后首先选择"1. 初始化数据库表"

2. **宿舍楼性别类型必须正确**
   - 5号楼、6号楼设置为"男"
   - 女生宿舍设置为"女"

3. **学生宿舍分配前必须先创建房间和床位**
   - 不能分配到不存在的床位

4. **查寝记录每个学生每天只能有一条**
   - 系统会自动使用 INSERT OR REPLACE

5. **请假状态判断**
   - 学生查寝记录状态为"请假"
   - 且该学生在该日期有已通过的请假申请
   - 才显示"请假不在校"状态

## 📞 常见问题

### Q1: 如何修改宿舍楼信息？
A: 目前系统不支持修改，需要删除后重新添加。

### Q2: 学生可以更换宿舍吗？
A: 可以，直接重新分配新的宿舍即可，系统会自动将旧分配标记为无效。

### Q3: 如何批量导入学生宿舍分配？
A: 可以编写Python脚本，调用 `assign_student_to_dormitory()` 方法批量导入。

### Q4: 请假申请可以撤销吗？
A: 可以，将 ApprovalStatus 设置为"已撤销"。

### Q5: 如何查看历史查寝记录？
A: 查询 DormitoryCheckInRecords 表，指定日期范围即可。

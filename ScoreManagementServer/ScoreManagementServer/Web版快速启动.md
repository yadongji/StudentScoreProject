## 👥 四个角色，简单易用

### 1️⃣ 系统管理员

**做什么：**
- 管理宿舍楼（5号楼、6号楼等）
- 管理宿管人员
- 查看系统统计

**怎么用：**
1. 打开浏览器
2. 登录（任意用户名密码）
3. 选择角色：系统管理员
4. 开始管理

---

### 2️⃣ 宿管阿姨

**做什么：**
- 查看今日查寝统计
- 记录每晚查寝情况
- 查看房间入住信息

**怎么用：**
1. 登录系统，选择角色：宿管阿姨
2. 查看今日查寝统计
3. 点击"查寝记录"
4. 为每个学生选择状态：
   - ✅ 在寝
   - ❌ 未归
   - 🟡 请假
   - 🔵 外出
   - 🟣 晚归
5. 提交记录

**使用场景：**
```
晚上10点，宿管王阿姨拿出手机：
1. 打开浏览器访问系统
2. 进入"查寝记录"
3. 看到负责的5号楼1楼10个房间
4. 为每个学生点选状态
5. 一键提交完成查寝
```

---

### 3️⃣ 班主任

**做什么：**
- 查看班级出勤情况
- 审批学生请假申请

**怎么用：**
1. 登录系统，选择角色：班主任
2. 查看班级今日出勤
3. 点击"请假审批"
4. 点击"通过"或"拒绝"
5. 添加备注（可选）

**使用场景：**
```
张老师早上到校：
1. 打开电脑查看系统
2. 看到高一(1)班50人，请假2人
3. 进入"请假审批"
4. 看到李四的请假申请（事假）
5. 审批通过
```

---

### 4️⃣ 学生家长

**做什么：**
- 查看学生信息
- 为孩子申请请假
- 查看请假记录

**怎么用：**
1. 登录系统，选择角色：学生家长
2. 查看孩子信息和今日状态
3. 点击"申请请假"
4. 填写请假表：
   - 请假类型：病假/事假
   - 请假原因
   - 开始和结束时间
   - 家长电话
5. 提交申请
6. 等待班主任审批

**使用场景：**
```
家长发现孩子发烧：
1. 打开手机访问系统
2. 进入"申请请假"
3. 填写：病假，发烧去医院，1天
4. 提交申请
5. 查看状态：待审批 → 已通过
```

## 📱 手机访问设置

### 查看本机IP

1. 电脑按 `Win + R`
2. 输入 `cmd`
3. 输入 `ipconfig`
4. 找到IPv4地址：`192.168.1.100`

### 手机访问

```
http://192.168.1.100:5000
```

**重要：**
- ✅ 电脑和手机在同一WiFi
- ✅ 防火墙允许端口5000

## 📞 常见问题

### Q1: 无法访问系统

**A:**
1. 检查服务器是否启动（查看命令行窗口）
2. 检查浏览器地址是否正确
3. 清除浏览器缓存（Ctrl + F5）

### Q2: Flask未安装

**A:**
```bash
pip install Flask
```

### Q3: 手机无法访问

**A:**
1. 确认电脑和手机在同一WiFi
2. 查看本机IP（ipconfig）
3. 检查防火墙设置

### Q4: 数据库未初始化

**A:**
1. 运行命令行版：宿舍管理系统.bat
2. 选择"1. 初始化数据库表"
3. 重新启动Web服务器

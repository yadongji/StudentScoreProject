# Excel导入工具 V2.0 - 方向名次格式支持说明

## 更新说明

Excel导入工具V2.0现已支持方向名次格式（赋分成绩）的Excel文件导入。

---

## 支持的格式

### 1. 普通格式（原有功能）
- 单行表头（第1行）
- 学科成绩列
- 班级排名/年级排名列

### 2. 方向名次格式（新增功能）
- **Excel结构**：
  - 第1行：考试名称（合并单元格）
  - 第2行：空行
  - 第3行：学科名称（如"学校"、"班级"、"考号"、"姓名"、"选科"、"总分(物理)(赋分)"、"化学(赋分)"）
  - 第4行：字段类型（"分数"、"方向全体名次"、"方向校名次"、"方向班名次"）
  - 第5行：空行
  - 第6行开始：实际数据

- **学科列结构**：
  - 每个学科占4列：分数、方向全体名次、方向校名次、方向班名次

- **规则**：
  - ✅ 如果存在带"(赋分)"和普通两个版本，优先选择带"(赋分)"的
  - ✅ 如果只有普通版本（无"(赋分)"），选择这个版本
  - ✅ 映射"方向校名次"→"校名次"（GradeRank）
  - ✅ 映射"方向班名次"→"班级名次"（ClassRank）

## 字段映射规则

### 基础信息字段
| Excel列名 | 数据库字段 | 说明 |
|-----------|-----------|------|
| 学校 | - | 仅显示，不导入 |
| 班级 | ClassName | 用于匹配学生 |
| 考号 | StudentNumber | 优先使用学号匹配 |
| 姓名 | StudentName | 备用：学号不存在时使用姓名匹配 |
| 选科 | - | 仅显示，不导入 |

### 学科成绩字段
| Excel列结构 | 数据库字段 | 说明 |
|-------------|-----------|------|
| 学科名(赋分) - 分数 | Score | 赋分成绩 |
| 学科名(赋分) - 方向校名次 | GradeRank | 年级排名 |
| 学科名(赋分) - 方向班名次 | ClassRank | 班级排名 |
| 学科名 - 分数 | Score | 普通成绩 |
| 学科名 - 方向校名次 | GradeRank | 年级排名 |
| 学科名 - 方向班名次 | ClassRank | 班级排名 |

### 示例1：有赋分版本
```
Excel列6: 总分(物理)(赋分)  → SubjectId=10（总分）
Excel列7: 方向全体名次      → 忽略
Excel列8: 方向校名次        → GradeRank（年级排名）
Excel列9: 方向班名次        → ClassRank（班级排名）

Excel列10: 总分(物理)      → 跳过（已有赋分版本）
```

### 示例2：只有普通版本
```
Excel列14: 语文            → SubjectId=1（语文）
Excel列15: 方向全体名次    → 忽略
Excel列16: 方向校名次      → GradeRank（年级排名）
Excel列17: 方向班名次      → ClassRank（班级排名）
```

## 导入规则

### 1. 学科选择规则
- ✅ 如果同一个学科有两个版本（一个带"(赋分)"，一个不带），选择带"(赋分)"的
  - 如：`总分(物理)(赋分)` ✅ 导入
  - 如：`总分(物理)` ❌ 跳过（已有赋分版本）
  - 如：`化学(赋分)` ✅ 导入
  - 如：`化学` ❌ 跳过（已有赋分版本）

- ✅ 如果只有一个版本（无论是否带"(赋分)"），导入这个版本
  - 如：`语文` ✅ 导入（只有普通版本）
  - 如：`数学` ✅ 导入（只有普通版本）
  - 如：`英语` ✅ 导入（只有普通版本）

### 2. 学生匹配规则
- 优先使用学号匹配
- 如果学号为空或不存在，则使用姓名匹配
- 如果同班有多个同名学生，使用第一个

### 3. 考号字段处理
- Excel中的"考号"列会被识别为"学号"
- 用于匹配数据库中的学生
- 不导入到数据库

### 4. 总分字段处理
- `总分(物理)(赋分)` 中的 `(物理)` 会被忽略
- 只识别"总分"作为学科名
- SubjectId固定为10

## 常见问题

### Q1: 为什么有些学科没有被导入？
**A:**
- 如果学科有带"(赋分)"和普通两个版本，系统会导入带"(赋分)"的版本，跳过普通版本
- 如果学科只有普通版本（无"(赋分)"），系统会导入这个版本
- 确保Excel文件中包含相应版本的列

### Q2: "总分(物理)(赋分)"会被识别为什么？
**A:** 会被识别为"总分"（SubjectId=10），括号中的"(物理)"会被忽略。

### Q3: 如果Excel中没有学号，还能导入吗？
**A:** 可以。如果Excel中没有学号列或学号为空，系统会尝试用姓名匹配学生。但建议优先使用学号，避免同名学生混淆。

### Q4: "方向全体名次"列会被导入吗？
**A:** 不会。系统只导入"方向校名次"和"方向班名次"。"方向全体名次"列会被忽略。

### Q5: 导入后，数据库中"校名次"和"班级名次"对应哪个Excel列？
**A:**
- 数据库的"GradeRank"（校名次） ← Excel的"方向校名次"
- 数据库的"ClassRank"（班级名次）← Excel的"方向班名次"

### Q6: 我的Excel中有"语文"和"语文(赋分)"两个版本，会导入哪个？
**A:** 会导入"语文(赋分)"版本，跳过"语文"版本。

### Q7: 我的Excel中只有"语文"一个版本，没有"语文(赋分)"，会导入吗？
**A:** 会。如果只有一个版本，无论是否带"(赋分)"，都会导入。

## 技术细节

### 方向名次格式检测逻辑
1. 读取Excel第3行和第4行
2. 检测是否包含"(赋分)"、"方向校名次"、"方向班名次"等关键字
3. 如果检测到，标记为方向名次格式
4. **扫描所有学科**：记录每个学科的赋分版本和普通版本的列范围
5. **选择学科版本**：
   - 如果存在赋分版本，选择赋分版本
   - 如果只有普通版本，选择普通版本
6. 提取学科名（优先匹配"总分"）
7. 分析选择的版本，提取分数、方向校名次、方向班名次列

### 数据读取逻辑
- 普通格式：从第2行开始读取数据
- 方向名次格式：从第6行开始读取数据
  - 第1行：考试名称
  - 第2行：空行
  - 第3行：学科名
  - 第4行：字段类型
  - 第5行：空行
  - 第6行开始：数据

# 宿舍管理系统 - Web版使用说明

## 🎉 Web版简介

这是一个基于Flask的Web应用程序，宿管阿姨、班主任、学生家长都可以通过浏览器或手机访问，非常方便！

### ✨ 主要特点

- 🌐 **Web界面** - 无需安装，浏览器访问即可
- 📱 **移动友好** - 支持手机、平板访问
- 🎨 **美观界面** - 使用Bootstrap 5设计
- 👥 **多角色** - 管理员、宿管、班主任、家长
- 🔔 **实时通知** - 操作即时反馈

---

## 🚀 快速开始

### 第一步：安装Flask

```bash
# 方法1：使用批处理文件（推荐）
双击运行：启动Web服务器.bat
系统会自动安装Flask

# 方法2：手动安装
pip install Flask
```

### 第二步：启动服务器

```bash
# 方法1：使用批处理文件
双击运行：启动Web服务器.bat

# 方法2：命令行运行
python app.py
```

### 第三步：访问系统

**电脑访问：**
```
http://127.0.0.1:5000
```

**手机访问：**
```
http://[本机IP]:5000
```
- 查看本机IP：在命令行输入 `ipconfig`
- 手机和电脑必须在同一WiFi网络下

## 👥 用户角色和使用场景

### 1. 系统管理员

**功能：**
- 管理宿舍楼信息
- 管理宿管人员
- 查看系统统计

**使用步骤：**
1. 打开浏览器访问 `http://127.0.0.1:5000`
2. 点击"登录"
3. 输入任意用户名和密码
4. 选择角色：系统管理员
5. 点击"登录"

**主要操作：**
- 添加宿舍楼（如：5号楼、6号楼）
- 查看宿舍楼统计信息
- 添加宿管人员
- 查看宿管人员列表

---

### 2. 宿管阿姨

**功能：**
- 查看每日查寝统计
- 记录查寝情况
- 查看房间入住情况

**使用步骤：**
1. 登录系统，选择角色：宿管阿姨
2. 查看今日查寝统计
3. 点击"查寝记录"
4. 为每个学生选择状态：
   - 在寝 - 正常就寝
   - 未归 - 未按时归寝
   - 请假 - 已批准请假
   - 外出 - 外出活动
   - 晚归 - 晚归
5. 点击"提交查寝记录"

**使用场景：**
```
晚上10点，宿管王阿姨开始查寝：
1. 打开手机浏览器，访问系统
2. 进入"查寝记录"页面
3. 查看今天负责的楼层（如5号楼1楼）
4. 为每个学生选择状态：
   - 张三：在寝 ✅
   - 李四：请假（请假申请已通过）
   - 王五：未归 ❌
   - 赵六：在寝 ✅
5. 提交记录
```

---

### 3. 班主任

**功能：**
- 查看班级出勤情况
- 审批学生请假申请

**使用步骤：**
1. 登录系统，选择角色：班主任
2. 查看班级今日出勤统计
3. 点击"请假审批"查看待审批的申请
4. 选择申请，点击"通过"或"拒绝"
5. 添加审批备注（可选）

**使用场景：**
```
张老师（高一(1)班班主任）查看班级出勤：
1. 打开电脑或手机访问系统
2. 进入"班级出勤"页面
3. 看到所有学生的今日状态：
   - 张三：请假不在校（病假，已通过）
   - 李四：在校
   - 王五：在校
   - 赵六：未查寝
4. 进入"请假审批"
5. 看到李四的请假申请（事假）
6. 审批意见：批准
```

---

### 4. 学生家长

**功能：**
- 查看学生信息和出勤状态
- 为学生申请请假
- 查看请假历史记录

**使用步骤：**
1. 登录系统，选择角色：学生家长
2. 查看学生基本信息和宿舍信息
3. 查看今日出勤状态
4. 点击"申请请假"
5. 填写请假申请表：

   - 填写家长联系电话

6. 等待班主任审批
7. 查看"请假记录"了解审批状态

**使用场景：**
```
家长为孩子请假：
1. 孩子感冒，需要请假1天
2. 家长打开手机，访问系统
3. 进入"申请请假"页面
4. 填写：
   - 请假类型：病假
   - 请假原因：发烧去医院
   - 开始时间：2026-01-22 08:00
   - 结束时间：2026-01-23 08:00
   - 联系电话：13900139001
5. 点击"提交申请"
6. 系统显示"提交成功"
7. 等待班主任审批
8. 审批通过后，系统显示"已通过"
```

## 📱 手机访问设置

### 方法1：查看本机IP

1. 在电脑上按 `Win + R`
2. 输入 `cmd` 并回车
3. 输入 `ipconfig` 并回车
4. 找到"无线局域网适配器"下的IPv4地址，如：`192.168.1.100`
5. 手机浏览器访问：`http://192.168.1.100:5000`

### 方法2：使用手机热点

1. 电脑连接手机热点
2. 在手机上查看IP地址
3. 手机浏览器访问：`http://[IP地址]:5000`

### 注意事项

- ⚠️ 电脑和手机必须在同一WiFi网络
- ⚠️ 确保电脑防火墙允许端口5000
- ⚠️ 服务器运行期间才能访问

## 🔧 故障排除

### 问题1：无法访问

**原因**：服务器未启动

**解决方法**：
- 检查是否运行了 `启动Web服务器.bat`
- 检查命令行窗口是否有错误

### 问题2：Flask未安装

**原因**：Python环境中没有Flask

**解决方法**：
```bash
pip install Flask
```

### 问题3：手机无法访问

**原因**：
- 电脑和手机不在同一网络
- 防火墙阻止了连接

**解决方法**：
- 确保电脑和手机在同一WiFi
- 临时关闭防火墙测试
- 添加防火墙例外规则

### 问题4：页面显示异常

**原因**：浏览器缓存问题

**解决方法**：
- 按 `Ctrl + F5` 刷新页面
- 清除浏览器缓存

## 📊 数据库操作

### 查看宿舍楼信息

```sql
SELECT * FROM vw_DormitorySummary
ORDER BY DormitoryCode;
```

### 查看今日查寝统计

```sql
SELECT
    CheckInDate,
    SUM(CASE WHEN Status = '在寝' THEN 1 ELSE 0 END) as PresentCount,
    SUM(CASE WHEN Status = '未归' THEN 1 ELSE 0 END) as AbsentCount
FROM DormitoryCheckInRecords
WHERE CheckInDate = date('now', 'localtime')
GROUP BY CheckInDate;
```

### 查看请假申请

```sql
SELECT * FROM vw_LeaveApplicationDetail
WHERE ClassName = '高一(1)班'
ORDER BY CreatedAt DESC;
```

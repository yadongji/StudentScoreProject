# V3.2 更新说明 - 修复列检测问题

## 🐛 问题描述

### 原始问题
用户在导入 `108班成绩统计表.xlsx` 时发现：
- 数据库中的 `ClassRank` 和 `GradeRank` 字段为空
- 控制台显示的字段映射错误：

```
班级: 列4 (班级名次)  ← 错误！应该是列1
姓名: 列1 (姓名)     ← 错误！应该是列2
学校: 列3 (学校名次)  ← 错误！应该是列4
```

### 问题根源

Excel表格结构为：
```
列1: 班级 | 列2: 姓名 | 列3: 总分 | 列4: 学校名次 | 列5: 班级名次 | 列6: 语文 | 列7: 班次 | 列8: 校次 | ...
```

但旧的列检测逻辑使用包含匹配，导致：
- `班级名次` 包含 `班级`，被误识别为班级列
- `学校名次` 包含 `学校`，被误识别为学校列
- 学科排名字段没有被正确识别

---

## ✅ 修复方案

### 1. 基础信息列检测 - 优先精确匹配

**修改前（使用包含匹配）**：
```python
if '班级' in header:
    col_map['班级'] = idx
```

**修改后（优先精确匹配）**：
```python
if header == '班级':  # 优先精确匹配
    col_map['班级'] = idx
```

### 2. 学科列检测 - 使用相邻列判断

**修改前（单列独立判断）**：
```python
for subject in subjects:
    if subject in header:
        if '班次' in header:
            col_map[f'{subject}_class_rank'] = idx
```

**修改后（基于成绩列位置查找相邻列）**：
```python
# 第一步：找到所有学科的成绩列
subject_score_cols = {}
for idx, header in enumerate(header_row):
    for subject in subjects:
        if header == subject or (subject in header and not ('班次' in header or '校次' in header)):
            subject_score_cols[subject] = idx
            col_map[f'{subject}_score'] = idx
            break

# 第二步：基于成绩列位置，查找相邻的"班次"和"校次"列
for subject, score_col in subject_score_cols.items():
    for offset in range(1, 4):  # 检查后面3列
        col_idx = score_col + offset
        header = header_row[col_idx]

        # 判断是否为班次列
        if header == '班次' or header == '班级名次' or header == '班级排名':
            col_map[f'{subject}_class_rank'] = col_idx

        # 判断是否为校次列
        elif header == '校次' or header == '校名次' or header == '学校名次' or header == '年级名次':
            col_map[f'{subject}_grade_rank'] = col_idx

        # 遇到新的学科列就停止
        if header in subjects:
            break
```

## 🎯 使用建议

### Excel表格格式建议

**推荐格式**（标准表头）：
```
班级 | 姓名 | 总分 | 学校名次 | 班级名次 | 语文 | 班次 | 校次 | 数学 | 班次 | 校次
```

**也支持**（使用别名）：
```
班级 | 姓名 | 总分 | 校次 | 班次 | 语文 | 班次 | 校次 | 数学 | 班次 | 校次
```

**还支持**（使用其他变体）：
```
班级 | 姓名 | 总分 | 年级名次 | 班级排名 | 语文 | 班级排名 | 年级排名 | 数学 | ...
```

### 排名字段位置规则

- 总分后面紧跟：`学校名次`（或`校次`）和`班级名次`（或`班次`）
- 学科后面紧跟：`班次`（或`班级名次`）和`校次`（或`校名次`）

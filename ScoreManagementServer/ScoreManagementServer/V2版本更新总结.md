## Excel结构要求

### 方向名次格式
```
第1行：考试名称（合并单元格）
  例如：总分(物理)_学生成绩(方向名次)_2026020203九师联盟高一考试河南

第2行：空行

第3行：学科名称
  列1: 学校
  列2: 班级
  列3: 考号
  列4: 姓名
  列5: 选科
  列6: 总分(物理)(赋分)
  列10: 总分(物理)  ← 非赋分版本，会被跳过
  列14: 语文
  列18: 数学
  列22: 英语
  列26: 物理
  列30: 化学(赋分)
  ...

第4行：字段类型
  列6: 分数
  列7: 方向全体名次  ← 会被忽略
  列8: 方向校名次    → GradeRank
  列9: 方向班名次    → ClassRank

第5行：空行

第6行开始：实际数据
```

## 问题排查

### 问题：无法识别学科
**解决：**
- 检查Excel第3行是否包含学科名
- 如果学科有赋分版本，确保包含"(赋分)"标记
- 如果学科只有普通版本，确保学科名正确

### 问题：某些成绩未导入
**解决：**
- 如果学科有赋分版本和普通版本，系统只会导入赋分版本
- 如果学科只有普通版本，系统会导入这个版本
- 确认Excel中是否包含相应版本的列

### 问题：学生匹配失败
**解决：**
- 确保数据库中已存在学生
- 检查学号或姓名是否正确
- 使用"4. 更新学生信息"功能先导入学生

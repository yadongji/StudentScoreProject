# 班级排名分析工具完整功能说明

## 功能概述

班级排名分析工具提供三种分析模式：

### 1. 学生个人排名变化分析（对比最近两次考试）
- 对比最近两次考试的排名变化
- 显示进步和退步的学生列表
- 支持设置退步显示阈值
- 支持导出Excel表格

### 2. 班级学科排名总和变化分析
- 分析班级整体的排名趋势
- 显示每次考试的排名总和变化
- 评估班级整体表现

### 3. 多次考试详细排名变化分析（按学期查看所有考试）- **推荐** ⭐
- 显示历次考试的详细排名
- 显示相邻两次考试之间的排名变化
- 支持按学期查看数据
- 支持按进步/退步排序
- 进步用**红色**字体和**↑**箭头+名次表示
- 退步用**绿色**字体和**↓**箭头+名次表示
- 保持不变用**→**表示
- 最后一列显示从第一次到最后一次的总变化
- 支持导出Excel表格，样式与控制台输出一致

## 模式1：学生个人排名变化分析（最近两次考试）

### 使用步骤

1. **启动工具**
   ```bash
   双击运行：查看班级排名可视化.bat
   ```

2. **选择班级**
   - 输入班级编号（如：1、2、3...）

3. **选择科目**
   - 输入科目编号（如：1. 总分、2. 语文、3. 数学...）

4. **选择分析类型**
   ```
   1. 学生个人排名变化分析（对比最近两次考试）
   2. 班级学科排名总和变化分析
   3. 多次考试详细排名变化分析（按学期查看所有考试）
   ```
   - 输入 **1** 选择此模式

5. **选择排名类型**
   ```
   1. 年级排名（默认）
   2. 班级排名
   ```
   - 输入 1 或 2

6. **查看结果**
   - 系统自动获取最近两次考试
   - 显示进步学生列表（进步最多的在前）
   - 显示明显退步学生列表（可设置阈值）
   - 显示统计摘要（进步人数、退步人数、平均变化等）

7. **导出Excel**
   - 询问是否生成Excel报告时，输入 `y`
   - Excel文件会保存到桌面
   - 文件名格式：`班级名_考试A_to_考试B_科目名.xlsx`

## 模式3：多次考试详细排名变化分析（推荐）⭐

### 使用步骤

1-3. 同模式1

4. **选择分析类型**
   ```
   1. 学生个人排名变化分析（对比最近两次考试）
   2. 班级学科排名总和变化分析
   3. 多次考试详细排名变化分析（按学期查看所有考试）
   ```
   - 输入 **3** 选择此模式

5. **选择排名类型**
   ```
   1. 年级排名（默认）
   2. 班级排名
   ```
   - 输入 1 或 2

6. **选择学期**
   - 系统会自动获取该科目所有考试
   - 按学期分组显示
   - 只显示有成绩记录的学期
   - 如：
     ```
     ================================================================
       选择学期
     ================================================================
       1. 2024年第一学期（上学期）(2024-09-01 至 2025-02-01, 共3次考试)
       2. 2025年第二学期（下学期）(2025-03-01 至 2025-06-15, 共2次考试)
     ================================================================
     ```
   - 输入学期编号进行选择

7. **查看结果**
   - 显示该学期所有考试的详细排名变化表格
   - 进步用**红色**↑显示
   - 退步用**绿色**↓显示
   - 保持不变用黑色→显示
   - 无效数据用灰色-显示

8. **选择排序方式** ⭐ 新功能
   ```
     ================================================================
       选择排序方式
     ================================================================
       1. 按总变化排序（进步最多的在前）
       2. 按学号排序（默认）
     ================================================================
   ```
   - **按总变化排序**（推荐）：
     - 总变化为正（进步）的学生排在最前面
       - 进步越多，排名越靠前
       - 例如：↑20, ↑15, ↑10, ↑5, ↑1
     - 总变化为0（不变）的学生排在中间
     - 总变化为负（退步）的学生排在最后面
       - 退步越少，排名越靠前
       - 例如：↓2, ↓5, ↓10, ↓15
   - **按学号排序**：按学号从小到大排序

9. **导出Excel**
   - 询问是否生成Excel报告时，输入 `y`
   - Excel文件会保存到桌面
   - 文件名格式：`班级名_多考次排名变化_科目名.xlsx`
   - Excel中保持排序顺序（如果选择了按总变化排序）

## 颜色说明

### 控制台输出

- **红色** ↑数字：表示排名进步（数字越大，进步越多）
- **绿色** ↓数字：表示排名退步（数字越大，退步越多）
- **黑色** →：表示排名保持不变
- **灰色** -：表示排名数据缺失或无法计算

### Excel表格

- 进步（↑）：红色字体（#C00000）
- 退步（↓）：绿色字体（#00B050）
- 不变（→）：黑色字体
- 无效（-）：灰色字体（#999999）

## 排序逻辑详解

### 按总变化排序的规则

**排序优先级：**
1. **进步学生**（总变化 > 0）：排在最前面
   - 按进步名次从大到小排序
   - 例如：↑20, ↑15, ↑10, ↑5, ↑1
   - 进步最多的学生排第1

2. **保持不变学生**（总变化 = 0）：排在中间
   - 按学号排序

3. **退步学生**（总变化 < 0）：排在最后面
   - 按退步名次从小到大排序
   - 例如：↓2, ↓5, ↓10, ↓15
   - 退步最少的学生排在退步学生的最前面

4. **无数据学生**（总变化 = None）：排在最后
   - 按学号排序

**为什么这样排序？**
- 快速识别进步最多的学生，方便表扬和激励
- 快速识别需要关注的学生（退步较多的）
- 保持不变的学生在中间，一目了然

## 技术细节

### 1. 数据来源
- 从数据库的 `Scores` 表读取成绩
- 从 `Exams` 表读取考试信息
- 从 `Students` 表读取学生信息

### 2. 计算逻辑
- 相邻变化 = 上一次排名 - 当前排名（正数表示进步）
- 总变化 = 第一次排名 - 最后一次排名

### 3. 学期分组规则
- **第一学期（上学期）**：9月至次年2月
- **第二学期（下学期）**：3月至8月
- 根据考试日期自动分组
- 只显示有成绩记录的学期

### 4. 输出格式
- 控制台使用ANSI颜色代码
- Excel使用 openpyxl 样式
- 两者显示效果一致

### 5. 颜色方案
- 进步：红色（ANSI: \033[31m, Excel: #C00000）
- 退步：绿色（ANSI: \033[32m, Excel: #00B050）
- 保持不变：黑色
- 无效：灰色（#999999）

## 注意事项

1. **数据完整性**
   - 模式1：至少需要2次考试记录
   - 模式3：至少需要2次考试记录
   - 如果某次考试排名缺失，显示为"N/A"
   - 变化列显示为"-"

2. **学期选择**
   - 只显示有成绩记录的学期
   - 根据考试日期自动推断学期
   - 第一学期：9月-2月
   - 第二学期：3月-8月

3. **排名类型**
   - 可以选择"年级排名"或"班级排名"
   - 两种排名的计算方式不同
   - 建议根据实际需求选择

4. **Excel文件**
   - 文件保存在桌面
   - 每次生成会覆盖同名文件
   - 建议及时备份重要数据
   - 排序后的数据在Excel中保持顺序

5. **排序功能**
   - 只在模式3中可用
   - 排序不影响原始数据
   - 可以重新运行工具选择不同排序方式

## 常见问题

**Q: 为什么模式3需要选择学期？**  
A: 学期选择可以帮助您聚焦分析特定时间段的表现，避免跨越太长时间的数据混杂在一起，使分析更加精准。

**Q: 如果某个学生某次考试缺考怎么办？**  
A: 缺考学生的该次考试显示为"N/A"，变化列显示为"-"，不会影响其他学生或该学生其他次考试的分析。

**Q: Excel表格可以手动排序吗？**  
A: 可以。Excel表格保存的是原始数据，您可以自由使用Excel的排序功能进行任何方式的排序。

**Q: 排名总和变化是什么意思？**  
A: 排名总和是将班级所有学生的某次考试排名相加的总和。排名总和越小，说明班级整体表现越好。

**Q: 如何快速识别进步最多的学生？**  
A: 使用模式3，选择"按总变化排序"，进步最多的学生会排在最前面，一目了然。
